分析流程

数据落在这台机器上处理，产物是自包含文件，发给别人双击就能看。按下面的顺序走，也可以随时跳到任意一步。

这页能处理什么

  • 表格 xlsx / xlsm / xls / csv / tsv：多 sheet 逐个导入，GBK 与分号、竖线分隔自动识别，合并单元格前向填充。
  • 文档 docx / txt / md：抽内嵌表格，再从「指标：值」这类行里抽键值对。
  • PDF 文本型直接抽表；扫描件走视觉模型（需配大模型）。
  • 图片 png / jpg / webp / bmp：需配置大模型才能识别。
  • 粘贴 Markdown 表格优先，否则按 Tab、多空格、逗号或竖线自动分列。

数字怎么来的

  • 报告里的数字全部由后端聚合计算产出，大模型只把算好的数字改写成段落，不碰任何数值。
  • 全角数字、中文量级（1.2万 / 3亿）、货币符号加千分位、百分号都会识别成数值；「约1.2万」这种夹字的如实判为文本。
  • 列名含「率 / 占比」且值在 0~1.5 的列按百分比列处理，聚合出均值而不是求和。
  • 时间维度按自然排序，1月 2月 不会排成 1月 10月。
