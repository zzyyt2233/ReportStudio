# ReportStudio

把多源数据变成图表和结论报告。图片、PDF、Excel、Word、文本丢进去，或者从数据库取数，勾选（或一句话说清）要什么图，就出一份带交互图表的 HTML 报告，还能另存 Word / PDF。

代码、依赖、产物都落在项目自己的目录下，不往系统盘写东西，代码里也没有写死的盘符，整个目录拷到哪个盘都能直接跑。

## 本次更新

- 出图、导出、SQL 取数这些重活改到后台线程池跑（最多 4 个并发），出图期间界面照常可用，不再整个页面卡住等结果。
- 配了大模型接口的：接口连不上时 3 秒内快速报错，之后 5 分钟内直接走降级流程，不再每次请求都干等 60 秒超时。
- 历史报告列表加了元数据缓存，报告上千份时打开页面、搜索列表都不再变慢。
- 历史报告支持按天数批量清理：先列出会删多少份、释放多少空间，确认后才真删；每天的数据量和总量直接显示在列表上方。
- 界面整体过了一遍无障碍合规：文字对比度、表单标签与输入框的关联、纯键盘操作、读屏播报，达到 WCAG 2.2 AA。
- 视觉上做了减法：字号、圆角、底色统一成一套，减少线条和嵌套边框。
- 删除、清理这类操作的确认框改为页面内自绘，在内嵌预览窗口等会禁用系统弹窗的环境里也能正常操作。

## 启动

双击 `启动.bat`，浏览器自动打开 http://127.0.0.1:8765 。关掉黑窗口就停止服务。

- 免安装版（压缩包里有 `runtime` 文件夹）：解压后直接双击 `启动.bat`，不用装 Python，也不用联网。
- 源码版：第一次运行会自动建好虚拟环境、联网装依赖（约 100MB，几分钟），装完直接启动。不需要提前准备什么。
- 端口被占用时会自动顺延到 8766 / 8767，并按实际端口打开浏览器，不用手改配置。

等价的命令行：

```
python -m venv .venv
.venv\Scripts\python.exe app.py
```

## 怎么用

```
1 导入数据      拖拽 / 点选 / 粘贴表格 / 指定文件夹批量导入
2 数据库取数    选库类型 → 填连接 → 列表 → 写 SQL（只读）
3 数据预览      改表头行号、改列类型（数值 / 日期 / 文本），看解析提示
4 多文件整合    自动判断哪些表结构相同可合并，可手动改
5 说清需求      一句话描述，或直接勾选图表类型 / 横轴 / 数值 / 聚合 / 排序
6 生成报告      导出 Markdown / Word / PDF / 总图 PNG，或存成数据看板
```

底部预览区是「报告 / 看板」两个视图，点一下就切换，不用生成两次：

- 点「生成报告」，报告这一屏就地刷新。
- 切到「看板」会按当前配置和当前数据实时重算，改了图或换了数据，切过来就是最新的。
- 想长期留着这份看板，再到第 6 步起个名字点「保存到看板」。
- 预览框右上角「放大预览」会把预览区铺满浏览器窗口，屏幕小的时候比来回滚动省事。

报告里每张图右上角有「保存为 PNG」，点了直接下载 2 倍分辨率白底图，方便贴进 PPT。打印时这些按钮会自动隐藏。

页面底部是「历史报告」：按名字搜索、直接打开、补导出 Word / PDF、逐份删除。每行显示这份报告有几张图、几个指标、多少行、占多大。列表上方会显示全部报告的总份数和总占用；存量超过 50 份或 100MB 时出现「清理旧报告」按钮，输入保留天数（最少 7 天）后先预览会删多少、释放多少，确认才真删，删到一半超时会报告剩余数量，再点一次接着删。

## 图表怎么配

每个指标可以各选各的图型。一张图表卡里勾了「销售额、毛利率」，不用拆成两张卡：在「数值」下面每个已选指标各占一行，单独选它的图型——销售额画柱状、毛利率画折线，可以合并在同一张图里。想让所有指标都用同一种图型，改卡片顶上的「类型」，底下保持「跟随默认」。

饼图和散点图只能装一个指标，选中后会自动单独成图，界面上会写明。

勾两个以上指标时可选「多指标」：合并成一张图，或拆成多张单指标图。两个以上数列且图型合适时可勾「双轴」，第二个走右轴。

版面可选每行 1 / 2 / 3 张；每张图还能选在看板里的宽度（半宽 / 整宽 / 三分之一 / 四分之一）。

预览区的「导出总图」会把已画好的 PNG 拼成一张长图或网格图，方便一次转发。

## 支持什么输入

- 表格（xlsx / xlsm / xls / csv / tsv）：多 sheet 逐个导入；GBK、分号或竖线分隔自动识别；合并单元格前向填充。
- 文档（docx / txt / md）：抽内嵌表格，再从「指标：值」这类行里抽键值对。
- PDF（pdf）：文本型直接抽表；扫描件走视觉模型。
- 图片（png / jpg / webp / bmp）：需要配置大模型才能识别。
- 粘贴：Markdown 表格优先；否则按 Tab、多空格、逗号或竖线自动分列。

导入的表会落盘到 `session\`，关掉服务再打开还在，不用重新传。5 万行以上的表只放内存，7 天前的缓存自动清理，`config.yaml` 里 `session.persist: false` 可以关掉。

多种类型可以混着导，同构的自动合并、异构的各成章节。合并时同名列类型冲突会按「数字 > 日期 > 文本」取更精确的类型。

## 从数据库取数

连接库写 SQL 取回来的结果，和导入的表格一样走后面的出图链路。

- SQLite：不需要额外驱动。填 `.db / .sqlite` 路径，或点「上传库文件」。
- MySQL / MariaDB：需要 pymysql，端口默认 3306。
- PostgreSQL：需要 pg8000，端口默认 5432。
- SQL Server：需要 pyodbc，还要在本机装 ODBC 驱动，端口默认 1433。
- Oracle：需要 oracledb，端口默认 1521，`service` 填服务名而不是 SID。

驱动都在 `安装依赖.bat` 里装好了。

五步：选库类型 → 填连接（可「保存连接」下次直接选）→「连上并列表」→ 点表名自动生成 SELECT 模板 → 改 SQL → 「取数并出图」。

### 只读是硬约束

SQL 只能查，不能写。有三层闸门：语句闸门（只放行 SELECT / WITH 开头的单条语句，会先遮蔽注释和字符串字面量再扫关键词）、连接闸门（SQLite 用 `mode=ro` 打开，网络库连接后立即设为只读）、资源闸门（超时 30 秒、行数上限 20000 行，超了会截断并在报告里写明）。

`config.yaml` 的 `database.max_rows` / `timeout_ms` 可以调后两项，前两层没有开关。

建议给这个工具单独开一个只有 SELECT 权限的数据库账号。闸门是兜底，不是拿生产管理员账号来连的理由。

### 密码怎么存

连接配置存在项目目录下的 `db_connections.json`（已写进 `.gitignore`，不会进版本库）。接口返回的连接信息里只有 `has_password: true/false`，明文不会回显。密码是明文存盘的（本地单机工具），不想存就取消「记住密码」勾选。

## 数据看板

报告是长文档，往下滚着读、适合打印成册；看板是一屏，指标卡一行加图表网格平铺，打开就看完，适合挂屏幕上或汇报时截图。

看板保存的是「要哪几个指标、哪几张图、怎么排」，不是数字本身。所以数据更新之后，同一个看板点开就是新数据。

反过来，它依赖会话里的数据表。如果那些表被清理了，看板会照常打开，但会在页面顶部列出哪几张表没找到、哪些图被跳过了，并说明怎么恢复。

看板的具体能力：

- 布局：12 栅格网格，每张图可选半宽 / 整宽 / 三分之一 / 四分之一；窄屏自动变整宽。
- 指标卡：勾了「指标列」就按勾的来；不勾就按表里的数值列自动出。
- 放大看单张：每张图右上角「放大」，铺满一屏，还能看它背后的数据表、导出 CSV。
- 全屏 / 打印：右上角「全屏」；「打印 / 存 PDF」按横向铺满，按钮自动隐藏。
- 单图导出：每张图右上角「存 PNG」。

放大单张图时，类目多于 12 个会默认只显示前 12 个，底下有缩放条可以拖着看其余部分。

## 关于大模型（可选）

图片识别和文字润色需要大模型，结构化数据（Excel / CSV / docx / PDF 表格）完全不需要。

密钥写在 `config.local.yaml`，不要写在 `config.yaml`——后者是会跟着项目一起分享出去的公共模板，前者在 `.gitignore` 里、永远不会被提交。

```yaml
# 新建一个 config.local.yaml，只写要覆盖的项即可
llm:
  enabled: true
  base_url: "https://api.deepseek.com/v1"
  api_key: "sk-xxxx"
  model: "deepseek-chat"
```

三家通用，都是 OpenAI 兼容协议（DeepSeek、智谱 GLM、通义千问、本地 Ollama 都可以）。

没配置时的降级行为：

- 图片 / 扫描件识别：给出提示让你去配接口，其余文件照常处理。
- 自然语言需求解析：退回关键词规则解析，能应付「按X统计Y画柱状图降序」。
- 结论文字润色：用程序拼出的模板句式。

报告里展示的数字全部由 `core/analyze.py` 计算产出，大模型只负责把已算好的数字改写成通顺段落，不碰任何数值。

## 注意事项

### 数据核对

- 单位问题解析器救不了：列名叫「销售额(万元)」、单元格却填「3亿」时，只能按字面处理。这类单位混淆属于原始数据问题，请在预览阶段核对列单位。
- 列名含「率 / 占比」且值在 0~1.5 的列会判为百分比列，聚合时出均值而不是求和。
- 值只有 0/1/2 的标记列会数「1」的条数，标题里会注明口径。
- `N/A`、`-`、`—`、`/`、空单元格这些缺失占位符会被统一识别，不会把整列误判成文本。
- 分类列（省份、月份等）有空值时，这些行不计入图表，结论里会写明「有 N 行因某列为空未计入」。
- 重名列会自动改名（`金额` / `金额_1`），保证列名唯一、数据一个不丢。
- 时间维度会按自然排序（`1月 2月 … 12月` 不会排成 `1月 10月 11月 12月 2月`）。
- 饼图数据含负值时会改用柱状图，并在摘要里说明哪几个分类为负。

### 脏数据

全角数字（３５６）、中文量级（1.2万 / 3亿）、Unicode 减号、货币符号加千分位、百分号都能识别成数值。但「约1.2万」这种数字里夹文字的会如实判为文本，不强行猜。

所有来自文件的文本都会转义，列名叫「部门`<script>`」这类内容不会把页面搞坏。

### 发给别人

单份报告不需要对方装任何东西：`outputs/<报告名>/report.html` 是自包含的，ECharts 已经整个内嵌进去，不依赖 CDN，断网也能看，图表照样能交互。

- `report.html`：带交互图表的报告，双击即看。
- `report.md`：纯文本版，方便贴进别的系统。
- `charts/`：每张图的 PNG，写 PPT 时可用。

要把整个工具给别人，别带上这几样：`outputs/`（你的历史报告）、`session/`（你导入的原始数据）、`dashboards/`（你的看板）、`db_connections.json`（数据库地址和明文密码）、`.venv/`（依赖，对方会自己装）。这些都已经写进 `.gitignore`，走 Git 不会误传；直接拷文件夹的话要手动剔掉。

### 其他

- HTML 用 ECharts 交互图，Word / PDF 用 matplotlib 静态图，所以导出不依赖本机装 Node 或浏览器。
- 报告 HTML 因为内联了 ECharts 源码，单文件偏大（1MB 左右），换来的是拷给别人双击就能看。
- 上传的临时文件攒在 `temp\`，下次启动时会清掉 24 小时以前的。
- 删报告或看板时如果文件被占用，后端会改名成 `.deleted` 兜底。页面底部「历史报告」右上角有「清理缓存」按钮，会显示可回收的数量，点一下即可（正常的报告、看板配置和数据表都不在回收范围内）。
- 出报告、跑 SQL、导 Word/PDF 这些重活跑在线程池里（最多 4 个同时跑），所以出图期间界面照样能点、页面不卡。代价是同时开 5 个以上重活任务时后面的要排队等一下，这是有意为之——每个出图任务都带着一份完整数据表，四个已经是内存上限。
- 出报告时如果选中的数据表刚好被删了，会明确提示「选中的 N 张数据表已经不在了（可能刚被删除）」，而不是笼统地说「请先导入数据」。

## 出了问题怎么自己看

- 点「生成报告」弹「生成出错」或提示连不上服务：服务没在跑（黑窗口被关了）。双击 `启动.bat`，保持黑窗口开着，刷新页面。
- 提示端口被占用，改用 8766：正常，浏览器已按新端口打开。想用回 8765 就把上次那个黑窗口关掉。
- 弹「服务端出错（XXX）」：完整堆栈写在 `logs\error.log`，看最后一段。
- 历史报告里找不到某份报告：清空搜索框。列表默认只显示最近 50 份，搜索是走服务端的，能搜到全量。
- 报告里图少了 / 数字对不上：看导入后的预览区提示，按提示改列类型或表头行号。
- 连数据库报「缺少驱动」或超时：双击 `安装依赖.bat` 补装；SQL Server 还要单独装 ODBC 驱动。
- SQL 被拒「只允许查数」：设计如此。要改数据请用别的工具，这个工具只取数。
- 导出报「这份报告已过期」：重新点一次「生成报告」再导出。`outputs\` 里的文件一直都在。
- 打开看板少了几张图：看板顶部会列出具体是哪几张表没找到，重新导入数据后再打开即可。

也可以直接访问 http://127.0.0.1:8765/api/status ，能看到一串 JSON 就说明服务是活的。

## 目录说明

```
app.py                服务入口与所有 API
config.yaml           公共配置模板（可随项目分享）
config.local.yaml     自己的私密配置：API key 等（不入库，可以不存在）
db_connections.json   保存的数据库连接（密码明文，别提交到 git）
core/
  ├─ model.py         Dataset / ChartSpec / ReportSpec 数据结构
  ├─ config.py        配置加载，支持 config.local.yaml 覆盖
  ├─ ingest.py        按扩展名分发到解析器
  ├─ analyze.py       聚合、排序、指标卡、结论文案（数字只在这里产生）
  ├─ chartset.py      图块构造，报告与看板共用
  ├─ merge.py         同构探测与合并
  ├─ spec.py          自然语言 → 图表规格
  ├─ llm.py           大模型适配层
  ├─ db/              数据库取数（含只读闸门）
  ├─ dashboard.py     看板配置与存盘
  ├─ parsers/         tabular / document / pdf / image / paste
  └─ render/          echarts / static_chart / html_report / markdown / docx / pdf
web/                  前端页面（含本地 ECharts，离线可用）
outputs/<报告名>/     生成的报告，自包含，拷走也能看
dashboards/           看板配置与渲染结果
samples/              测试数据生成器
tests/                回归套件
```

想先拿假数据试一遍功能：`.venv\Scripts\python.exe samples\make_samples.py`
